# spfx-tool — active project

## goal
SPFx room reservation dashboard: capa de presentación sobre el stack existente
(SharePoint + Power Apps + Power Automate + Outlook).
Fast room discovery, availability visibility, quick booking shortcuts — reutilizando toda la lógica existente.

## constraints
- Sin acceso a tenant SharePoint — cliente sube .sppkg
- Dashboard muestra y crea items; Power Platform valida/aprueba/orquesta
- Zero duplicación de lógica existente
- Output: .sppkg limpio listo para hand-off

## existing components (do NOT replace)

### SharePoint lists
Rooms: Title | RoomCode | Capacity | ImageName (único campo nuevo — single line of text)
RoomReservations: Title | Room | Start Date and Time | End Date and Time | Requested By |
  Status | Approver Comments | Approval Outcome | Recurring Booking | Recurrence Pattern |
  Repeat Until | End Date of the Series | Series ID | Flow Processed | Event ID |
  Created | Modified | Created By | Modified By

### Power Automate — Room Reservations Approval (DO NOT TOUCH)
Handles: conflict detection | availability validation | approval routing | approval decisions |
  email notifications | recurring reservations | calendar create/update | status management

### Power Apps (DO NOT TOUCH)
Handles: reservation creation | future date restrictions | time selection (15min increments) |
  basic validation | recurring booking inputs

## architecture
- Runtime: Podman rootless container (localhost/spfx-dev:latest, node:22-bookworm-slim)
- Source: ~/unix-toolkit-tools/spfx-tool/ → deploy: ~/dev/spfx/
- Projects: ~/dev/spfx/projects/<name>/
- Dev server: heft start, port 4321, --network=host
- Build pipeline: gulp bundle --ship + gulp package-solution --ship → .sppkg
- .sppkg output: projects/<name>/sharepoint/solution/

## data layer
SPFx Dashboard → RoomService → Rooms + RoomReservations + Site Assets
No direct Power Automate dependency. Flow triggers independently on list item creation.

## asset strategy
- Location: Site Assets/rooms/
- ImageName column → URL dinámica
- Fallback: room-placeholder.jpg (siempre presente)

## PATH setup (canonical)
- bootstrap escribe en ~/.zshenv.local (nunca en dotfiles versionados)
- ~/.zshenv (zsh-setup) sourcea ~/.zshenv.local al final
- ~/.zshenv.local: machine-local, no versionado, fuera de todo repo

## availability states (visual only — Power Automate es autoridad final)
Busy           — reserva activa ahora
Available Soon — próxima reserva en ≤30 minutos
Available      — sin reserva activa ni inmediata
